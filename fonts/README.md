# Fonts

Gambarino and Switzer are Fontshare typefaces, used by the selected reference and served locally here to avoid runtime font-service dependencies.

Typeface information and licensing: https://www.fontshare.com/ and https://www.fontshare.com/licenses

Downloaded from the reference's public Fontshare assets on Framer's font CDN. Gambarino is used for display headings; Switzer Regular and Medium are used for interface labels and body text.
