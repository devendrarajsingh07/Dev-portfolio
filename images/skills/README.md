Technology logos are vendored locally from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0), [Simple Icons](https://simpleicons.org/), and [Gymnasium](https://gymnasium.farama.org/). Library licenses are included in this directory. Brand trademarks remain with their respective owners.

Devicon: Python, Java, JavaScript, TypeScript, C, React, Next.js, HTML5, CSS3, Tailwind CSS, Three.js, Chart.js, D3, Node.js, Express, FastAPI, OpenCV, PyTorch, scikit-learn, pandas, PostgreSQL, MySQL, SQLite, Redis, Docker, Git, GitHub, Streamlit.
Simple Icons v14.15.0: Ultralytics, JSON Web Tokens. Qdrant was retrieved from the current Simple Icons package. Gymnasium's logo comes from its documentation.

SQL, reinforcement learning, document AI, and IoT symbols are original SVGs for general concepts.
